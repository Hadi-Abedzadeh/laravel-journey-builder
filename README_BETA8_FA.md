# Journey Builder v0.3.4-beta.8 — پیش‌نمایش پیام‌ها

این نسخه روی `v0.3.4-beta.7` ساخته شده و فقط رابط ویرایش جرنی را تغییر می‌دهد.

## تغییرات

- حذف ورودی «sign گیرنده (اختیاری)» از گره ایمیل و «فیلتر sign شماره گیرنده» از گره پیامک. مشخصات فنی قبلی در جرنی‌های ذخیره‌شده برای سازگاری دست‌نخورده باقی می‌مانند؛ گره‌های جدید این فیلتر را تنظیم نمی‌کنند. اگر قبلاً این فیلتر را تنظیم کرده‌اید، حذف آن از صفحه به معنی حذف خودکارش از جرنی قدیمی نیست.
- حذف نمایش «شناسه فنی گره» از پنل تنظیمات ویرایش. `node.id` در JSON و بک‌اند برای اتصال‌ها و گزارش‌ها باقی می‌ماند.
- دکمه «پیش‌نمایش» برای SMS، Email و Web Push در پنل تنظیمات گره‌ها، در حالت خواندنی و ویرایشی.
- پیش‌نمایش زنده از مقادیر فعلی فرم (بدون نیاز به ذخیره و بدون ارسال پیام).
- ایمیل: موضوع، حساب منتخب و متن ساده یا نمایش HTML در iframe سندباکس‌شده (اسکریپت و منابع خارجی مسدود).
- SMS: شبیه‌سازی گفت‌وگوی تلفن، متن با شکست خطوط، تعداد نویسه و Attribute گیرنده.
- Web Push: شبیه‌سازی اعلان، عنوان، متن، دکمه و لینک مقصد.
- استفاده از مقادیر آزمایشی برای متغیرها مثل `{{firstName}}`؛ نام Attributeهای نامشخص به صورت `[attribute]` نمایش داده می‌شود. هیچ اطلاعات واقعی کاربر خوانده نمی‌شود.

## فایل‌های تغییرکرده

- `resources/assets/builder.js`
- `resources/assets/journey-builder-pro.css`
- `resources/views/dashboard.blade.php`

هیچ Migration، Controller، Command یا تغییری در API پیامک، ایمیل و وب‌پوش وجود ندارد.

## انتشار روی GitHub و Packagist

فایل ZIP کامل را در **مخزن سورس خود پکیج** استخراج کنید (داخل `vendor` پروژه اصلی کپی نکنید). سپس:

```powershell
git add .
git commit -m "Add message previews and simplify node settings"
git push origin main
git tag -a v0.3.4-beta.8 -m "Preview email SMS and web push"
git push origin v0.3.4-beta.8
```

صبر نکنید تا نسخه از داخل `vendor` ویرایش شود؛ Packagist فقط نسخه‌ای را می‌شناسد که Git Tag جدید روی آن قرار گرفته. بعد از شناسایی Tag توسط Packagist (یا Update دستی آن)، داخل پروژه میزبان:

```powershell
cd D:\datasyncer
composer require "hadiabedzadeh/laravel-journey-builder:0.3.4-beta.8"
php artisan vendor:publish --tag=journey-builder-assets --force
php artisan view:clear
php artisan optimize:clear
```

**توجه:** `vendor:publish --force` فایل‌های CSS/JS منتشرشده را بازنویسی می‌کند؛ اگر آن‌ها را شخصی‌سازی کرده‌اید ابتدا پشتیبان بگیرید. سپس مرورگر را با `Ctrl+F5` تازه‌سازی کنید.

## بررسی بعد از نصب

1. در `/journeys/flows/{id}/edit` یک گره SMS را انتخاب کنید و از «پیش‌نمایش پیامک» استفاده کنید.
2. یک گره Email را انتخاب کنید، موضوع و متن ساده/HTML را وارد کنید و Popup را باز کنید.
3. یک گره Web Push را انتخاب کنید و Popup آن را بررسی کنید.
4. مطمئن شوید شناسه فنی گره و sign گیرنده در فرم نشان داده نمی‌شوند.
5. پیش‌نمایش، دکمه «ارسال» نیست و به سرویس خارجی وصل نمی‌شود.

**تست:** Syntax فایل JavaScript با `node --check` و PHP با `php -l` بررسی شده؛ اجرای end-to-end در Laravel و تست ارسال واقعی روی سرویس‌ها انجام نشده و برای این تغییرات ظاهری نیازی هم نیست. تست Playwright در این محیط به علت محدودیت دسترسی مرورگر قابل تکمیل نبود.
